# UI

Планируемая TypeScript/React библиотека общих компонентов и дизайн токенов storefront/admin. Владелец Frontend. Runtime/package manifest пока не создан.

Вход: утверждённый дизайн, [PRODUCT](../../docs/PRODUCT.md), [профиль Frontend](../../docs/agents/FRONTEND.md). Компоненты не обращаются к Ozon и не включают core business logic. Admin permissions проверяются сервером, не этим пакетом.
