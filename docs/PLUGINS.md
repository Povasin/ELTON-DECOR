# Плагины в работе Elton Decor

Подключение инструмента само по себе не меняет архитектуру. Использовать инструмент только для задачи, которую он решает. Нет необходимости создавать проект в каждом сервисе.

| Плагин | Задача | Профиль | Ограничение |
|---|---|---|---|
| GitHub | версия docs, исходники, issue/PR, evidence checks | все | единый репозиторий; не хранить secrets/BA приватные вложения |
| Superpowers | уточнение требований, планирование, разделение задач, review и verification | все | workflow не вправе переопределять запрос заказчика |
| Figma | согласованный storefront/admin дизайн, компоненты, доступность | Frontend + BA | дизайн не определяет auth, скидки или provider contract; читать mandatory skill перед соответствующим вызовом |
| MagicPath | исследование UX/прототип | Frontend + BA | утверждённые решения переносятся в Figma/docs; canvas не источник требований |
| Vercel | frontend preview; возможный hosting Next.js | QA/DevOps | отдельные storefront/admin targets одного repo; frontend secret не клиентская переменная; production topology пока не принято |
| Supabase | кандидат managed PostgreSQL/Storage | Architect + Backend/Ozon + QA/DevOps | не заменяет согласованный auth автоматически; одна система миграций Alembic, не второй schema owner; RLS если открыт Data API |
| Shopify | исследование альтернативы собственного commerce backend | BA + Architect | только ADR об изменении платформы; не добавлять параллельный checkout/источник заказов |
| Runway | будущие брендовые видео/медиа из разрешённых материалов | Frontend/контент | вне задачи подготовки архитектуры; не загружать PII/возвраты; проверять права и точность изображения товара |
| Higgsfield | будущие product/UGC видео, визуальный контент | Frontend/контент | вне core e-commerce; AI-изображение не заменяет достоверную фотографию конкретного товара |

- GitHub: доступ к репозиторию `Povasin/ELTON-DECOR`, исходно пустому; target является публичным. Публикуется только подготовленная документация и каркас.
- Vercel: поиск проектов по `elton` не вернул результатов в текущем контексте доступа. Deploy не выполнялся.
- Supabase: доступ к списку проектов подтверждён, Elton project не выбран/не создан. Чужой проект не подключался.
- MagicPath: список проектов доступен; подходящий созданный Elton дизайн не обнаружен в полученном списке. Дизайн не генерировался.
- Figma: reference links из интервью зафиксированы в SOURCES; в этой задаче дизайн не извлекался/не менялся.
- Runway/Higgsfield: медиа не генерировались; это опциональные инструменты будущего контента.
- Shopify: callable connector не обнаружен в доступном наборе текущего сеанса. Для подготовки docs это не блокер; Shopify архитектура не принята.

Это проверка текущего доступа, а не утверждение отсутствия ресурсов в иных аккаунтах/командах. Не включать IDs, адреса владельца или сведения о несвязанных проектах в публичные docs.

## Рекомендуемый цикл дизайна

BA сценарий и acceptance → MagicPath варианты при необходимости → Figma утверждённый макет → Frontend компоненты → QA accessibility/responsive/checkout → Vercel preview с синтетическими данными. Production deploy проходит отдельный gate.

Ozon ключи доступны только backend/worker runtime. Плагины генерации контента и будущий AI агент не получают merchant credentials.
